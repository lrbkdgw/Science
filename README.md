# ASTRA · 深空观测台

使用 **Three.js、TypeScript 和 Vite** 制作的交互式星系观测页面。三组独立的星尘纹理、分层发光星盘和三维恒星粒子，共同构成银河系、仙女座星系与涡状星系的艺术化重建。

## 启动

需要 Node.js 22.12+。

```bash
npm ci
npm run dev
```

```bash
npm run build    # TypeScript 检查与生产构建
npm run preview  # 预览 dist 中的生产版本
```

页面资源、字体和 Three.js 均随应用分发，运行时不依赖外部 CDN、API 或密钥。

## 观测操作

- **环绕与缩放**：拖动改变方位和倾角，滚轮或双指捏合缩放。双击星空或按 `R` 恢复默认视图。
- **星系切换**：点击导航卡片、左右箭头，或通过「星系图鉴」浏览档案并进入观测。
- **视图控制**：可切换轨道／俯视视角、调整旋转速度和星尘亮度，也可独立开关天体标注与轨道参考线。
- **标注与影像**：点击星系上的标签了解目标；相机按钮会导出带星系名、赤经与赤纬的 PNG 影像。
- **沉浸模式**：支持全屏与可选的合成空间音效。音效默认关闭，仅在用户主动开启后播放。

| 快捷键    | 操作               |
| --------- | ------------------ |
| `←` / `→` | 上一个／下一个星系 |
| `−` / `+` | 缩小／放大         |
| `Space`   | 暂停／继续自动旋转 |
| `R`       | 重置视图           |
| `F`       | 切换全屏           |
| `Esc`     | 关闭弹窗或退出全屏 |

## 实现

- `src/scene.ts`：透视相机、星尘体积分层、按纹理密度抽样的恒星粒子、自定义 GLSL 着色器、三维标注投影、手势和影像导出。
- `src/catalog.ts`：星系档案、天体标注、初始倾角与观测坐标。
- `src/main.ts`：中文控制界面、星系选择、图鉴与操作指南、Web Audio 空间音效。
- `src/style.css`：桌面与移动设备布局、观测面板和无障碍交互样式。
- `public/assets/`：本地 WebP 星系纹理、缩略图和深空背景。
- `public/fonts/`：Space Grotesk、IBM Plex Mono、精简中文字符集及字体许可。

桌面星系包含 34,000 个恒星粒子，手机使用 16,000 个，另有远景星场。画面使用受限的设备像素比；打开资料窗口或切至后台时暂停三维绘制。无 WebGL 2 时使用支持旋转、缩放的透视图像作为兼容视图。系统设置「减少动态效果」时，自动旋转默认关闭。

> 星系外观为艺术重建，天文数据为近似估计。颜色、时间和空间比例服务于交互展示，不用于精密测量。
